Reproduce and interpret

Train entirely on offline data; simulator interaction is for evaluation only. State-based observations include privileged object positions. GCBC is imitation learning; GCIQL and HIQL add value learning. Tests use fixed budgets and final checkpoints, with no success-driven checkpoint selection.
